# Fuente primaria — Pepperstone — Demo, API y protección de cliente

**Fecha de consulta de las tres páginas:** 04/08/2026. Método: WebFetch (HTML).

## 1) Caducidad de la cuenta demo

**URL:** https://pepperstone.com/en/help-and-support/opening-an-account/how-long-do-demo-accounts-last/

Cita: "MT4/5 demo accounts expire automatically after 60 days unless you have a live funded account
and request us to set it to non-expiry for you. cTrader demo accounts will not expire if they are
logged into at least once every 90 days."

Lectura: MT4/MT5 caduca a los 60 días desde la creación salvo conversión a no-caducidad (requiere
cuenta real financiada); cTrader no caduca si se accede al menos cada 90 días.

## 2) Acceso programático / API

**URL:** https://pepperstone.com/en-eu/platforms/integrations/api-trading/

Cita: la página menciona "cTrader Automate", descrito como una herramienta que permite "create and
optimise automated trading strategies using the cTrader platform's API and C# language", y una
sección general de "Algorithmic Trading".

Hueco declarado: esta página de aterrizaje NO detalla si existe una API REST/FIX de acceso directo
sin pasar por cTrader, ni requisitos de volumen mínimo. No se afirma nada sobre FIX API que no esté
en esta página (se descarta explícitamente una cifra de volumen mínimo para FIX API vista en fuentes
secundarias no admitidas, por no ser fuente primaria de Pepperstone verificada en esta sesión).

## 3) Protección de fondos y saldo negativo

**URL:** https://pepperstone.com/en-au/about-us/how-we-protect-you

**Advertencia de dominio:** esta URL es el dominio australiano (en-au) de Pepperstone, no el
específico de la entidad UK (Pepperstone Limited, FCA 684312) que se usa para el resto de columnas
de esta ficha. Se cita porque es la única página de protección al cliente localizada y accesible en
esta sesión; el contenido puede no aplicar palabra por palabra a la entidad UK, aunque la entidad UK
está listada entre los reguladores mencionados.

Citas:
> "Your money is kept in segregated client accounts at top-tier banks, separate from Pepperstone's
> own operational funds, so it cannot be used for business activities."
> "Negative balance protection for retail clients ensuring you can't lose more than you deposit; so
> if your account goes negative, we will restore it to zero." (la página aclara que esto NO aplica a
> clientes Pro/Professional)
> La página lista regulación de Pepperstone bajo ASIC, FCA, CySEC, BaFin, SCA, DFSA, CMA y SCB.

Hueco declarado: no se ha confirmado con fuente primaria específica de la entidad UK (Pepperstone
Limited) la cifra de cobertura del FSCS (esquema de compensación del Reino Unido); solo se afirma lo
que dice la página general citada arriba.
