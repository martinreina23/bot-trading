# Fuente primaria — TMGM — Cuenta demo (plataforma MT5)

**URL:** https://www.tmgm.com/en/platform/metatrader-5
**Fecha de consulta:** 04/08/2026. Método: WebFetch (HTML).

## Cita literal

> "TMGM MT5 demo accounts are valid for 30 days. If you need more practice time, you can create
> unlimited demo accounts"

## Lectura

Caducidad de 30 días desde la creación; se pueden crear cuentas demo ilimitadas con fondos virtuales
nuevos cada vez (a diferencia de Pepperstone, que sí permite convertir a "sin caducidad" con cuenta
real financiada — TMGM no lo declara aquí; **hueco** sobre si existe esa opción).

## Sobre API / trading automatizado (mismo documento)

La página menciona "Enhanced Expert Advisors" y "Comprehensive strategy tester" como herramientas de
MT5, que permiten trading algorítmico DENTRO de MetaTrader (EAs), pero no se ha localizado en esta
página ni en `tmgm.com/en/platform/tmgm-app` ninguna mención de una API REST/FIX independiente de
MetaTrader. Se declara **hueco** para una API propia de TMGM más allá de lo que ya ofrece el
estándar MT4/MT5 (Expert Advisors), que si cuenta como "acceso programático" en sentido amplio.
